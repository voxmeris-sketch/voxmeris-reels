Privacy Policy — Shorts Scheduler

Last updated: 3 October 2026

Who uses this app

Shorts Scheduler is a private tool used only by its owner (Voxmeris) to manage the owner's own YouTube channels, Voxmeris and Hoops Ranked. It is not offered to other people.

What it accesses

With the owner's permission (Google sign-in), the app uses the YouTube Data API to upload and schedule videos, update titles, descriptions, tags and playlists, read view and comment counts, and post comments — only on the owner's own channels.

What it stores

Sign-in tokens and upload records are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. No data about other YouTube users is collected or stored, apart from public comments on the owner's own videos, which are only shown to the owner.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
